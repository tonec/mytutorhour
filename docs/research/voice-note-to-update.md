# Feature Research: Voice note → lesson log + parent update

> Template: copy this file per feature (`docs/research/<feature>.md`).
> Status: In progress · Last updated: 2026-10-02

## Problem
After each lesson, tutors need to record what happened and keep parents informed. Today this takes 10-15 minutes, is done inconsistently, or is skipped, which hurts continuity and the parent relationship.

## Who has this problem
Independent tutors with 10-30 students, often teaching back-to-back lessons with little time between them.

## Current workarounds
- Notes app, Google Docs or Notion page per student
- Ad hoc WhatsApp or text messages to parents
- Pasting notes into ChatGPT to tidy them up
- Nothing at all (memory only)

## Existing landscape (unverified)
| Product | Type | Relevant? | Notes |
|---|---|---|---|
| Superprof / Tutorful / MyTutor / Preply / Wyzant | Marketplace | Partially | Lead gen; limited post-lesson tooling for off-platform students |

| Notion + ChatGPT | DIY | High (substitute) | Free, flexible, but manual and no memory per student |
| Calendly / Stripe | Generic | Adjacent | Scheduling and payments only |

**To verify:** whether any tool already offers voice-to-parent-update for tutors.

## Hypotheses
1. Tutors will record a 30-90 second voice note right after a lesson if the output is good enough to send with light edits.
2. Parents value a short, regular, specific update (more than a monthly summary).
3. Continuity (the "last time we…" context) is a meaningful differentiator from generic AI.
